Authentication

This API uses API key authentication. Generate and manage your keys from the Profile → API Keys section in the dashboard, then include the key in the Authorization header as shown below.

Using API Keys

Header Authentication

Include your API key in the Authorization header:

Authorization Header
Authorization: Bearer your_api_key_here

Example with Authentication

cURL with API Key
curl -X POST "{{ base_url }}" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer your_api_key_here" \
  -d '{"example": "value", "key": "data"}'
Python with API Key
import requests

url = "{{ base_url }}"
headers = {
    "Content-Type": "application/json",
    "Authorization": "Bearer your_api_key_here"
}
data = {"example": "value", "key": "data"}

response = requests.post(url, headers=headers, json=data)
print(response.json())
JavaScript with API Key
const response = await fetch('{{ base_url }}', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
        'Authorization': 'Bearer your_api_key_here'
    },
    body: JSON.stringify({
        example: 'value',
        key: 'data'
    })
});

const result = await response.json();
console.log(result);

Rate Limits

To ensure fair usage and optimal performance, the following rate limits apply:

Standard Limits

  • Requests per minute: 60
  • Requests per hour: 1,000
  • Requests per day: 10,000

Rate Limit Headers

  • X-RateLimit-Limit
  • X-RateLimit-Remaining
  • X-RateLimit-Reset

Code Examples

cURL Example
{{ curl_example }}
Python Example
import requests
import json

# API endpoint
url = "{{ base_url }}"

# Request data
data = {
    "example": "value",
    "key": "data"
}

# Make the request
response = requests.post(url, json=data)

# Handle the response
if response.status_code == 200:
    result = response.json()
    print("Success:", result)
else:
    print("Error:", response.status_code, response.text)
JavaScript Example
// API endpoint
const url = '{{ base_url }}';

// Request data
const data = {
    example: 'value',
    key: 'data'
};

// Make the request
fetch(url, {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
    },
    body: JSON.stringify(data)
})
.then(response => response.json())
.then(result => {
    console.log('Success:', result);
})
.catch(error => {
    console.error('Error:', error);
});
PHP Example

// Initialize cURL
$ch = curl_init();

curl_setopt($ch, CURLOPT_POST, true);

));

// Execute request

$httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
curl_close($ch);

// Handle response
if ($httpCode == 200) {
    $result = json_decode($response, true);
    echo "Success: " . print_r($result, true);
} else {
    echo "Error: " . $httpCode . " " . $response;
}
